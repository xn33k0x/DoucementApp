# Doucement

Prototype Android Kotlin d'un agent d'assistance téléphonique pensé pour les personnes anxieuses à l'idée de répondre au téléphone.

Prototype : écrans d'accueil, conversation simulée, historique, réglages et écran d'information sur le renvoi d'appel. La démo produit des réponses simples selon les mots-clés du message.

## Ouvrir
Importer ce projet dans Android Studio, synchroniser Gradle puis lancer sur émulateur ou appareil Android 8.0+.

## Limites
Ce prototype ne répond pas aux appels réels et n'active pas le renvoi opérateur. Une vraie version exige un backend sécurisé, un fournisseur télécom et une intégration vocale IA. Ne pas placer de clés API dans l'application.
